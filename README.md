# MIT_WPU_Apr2024

Data science and ML code from the MIT WPU session, April 2024 (three days).

## Contents

- `day1`: structured data analysis and Pandas
- `day2`: preprocessing and visualization
- `day3`: classification report and ML notebooks

Open the notebooks in Jupyter or Google Colab. The csv, json and xlsx files next to them are the datasets the notebooks use.
